# Changelog

## [1.4.0] - 2025-01-XX

### Added
- **新工具 `feishu_send_media`**：支持发送本地图片、视频、音频和文件到飞书
  - 图片（`.png`/`.jpg`/`.webp`/`.gif`）渲染为内嵌图片
  - 视频（`.mp4`/`.mov`/`.webm`/`.mkv`）渲染为视频播放器
  - 音频（`.ogg`/`.opus`/`.mp3`/`.m4a`）渲染为语音气泡
  - 其他文件类型渲染为文件下载卡片
  - 支持批量发送多个文件
  - 可通过 `kind` 参数强制指定渲染类型

### Fixed
- **修复双重回复问题**：当 Agent 使用 `feishu_send` 或 `feishu_send_media` 工具主动发送消息后，桥接不再自动发送最终文本回复，避免飞书收到重复消息
  - 检测到工具调用后自动抑制桥接的自动回复
  - 支持 cc-connect 的 `NO_REPLY` 约定
  - Agent 现在真正只与飞书用户对话，而不是同时与"飞书用户"和"会话中的虚拟用户"对话

### Changed
- 重构媒体上传逻辑，使用飞书官方 API（`/im/v1/images` 和 `/im/v1/files`）
- 添加入站媒体下载基础设施（为未来支持接收图片/文件做准备）
